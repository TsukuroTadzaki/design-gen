You are converting a design.json file into a human-readable design.md document.

## Input
You will receive a design.json file — the complete design specification for a website project.

## Your Task
Generate a well-structured Markdown document that presents all design decisions in a clear, readable format.

## Structure of design.md

### 1. Project Summary
- 3-4 sentences: what the business is, who the audience is, what the site should achieve
- Key differentiator

### 2. Brand
- **Headline**: the main headline
- **Subheadline**: supporting text
- **Slogan**: short memorable phrase
- **Positioning**: how the brand positions itself
- **Key Message**: the core message to the audience

### 3. Services
- List each service with icon, short description
- Note CTA text for each

### 4. Advantages
- List each advantage with icon, title, description

### 5. Target Audience
- For each avatar: name, age, situation, what they look for, fears, purchase trigger
- Present as readable profiles, not JSON

### 6. Objections & Answers
- Table or list format: objection → answer

### 7. Site Structure
- For each page:
  - Page name and purpose
  - List of sections with type, purpose, and key content points

### 8. Visual Direction
- Style recommendation with explanation
- Color palette: show each color with hex, role, and usage
- Visual language: photo style, shapes, textures, animations

### 9. CTA Strategy
- Primary and secondary CTA texts
- Touchpoints list

### 10. Content Plan
- What's available
- What's needed
- Placeholder strategy

## Rules
- Write in the same language as the design.json content
- Use headers, lists, and tables for readability
- Do NOT add opinions or suggestions — just present the data
- Do NOT skip any section — present everything from design.json
